# go-atjwt

Package **atjwt** implements ATProto's JSON Web Tokens — ATProto's rules, and the space tokens — for the Go programming language.

## Documention

Online documentation, which includes examples, can be found at: http://godoc.org/github.com/reiver/go-atjwt

[![GoDoc](https://godoc.org/github.com/reiver/go-atjwt?status.svg)](https://godoc.org/github.com/reiver/go-atjwt)

## Import

To import package **atjwt** use `import` code like the follownig:

```
import "github.com/reiver/go-atjwt"
```

## Installation

To install package **atjwt** do the following:

```
GOPROXY=direct go get https://github.com/reiver/go-atjwt
```
